# [가상] 6조 직무별 앱 모음

교육용 프로토타입입니다. 한 링크 안에 직무별 앱 3개를 탭으로 나란히 둡니다.

- ① 도면: 요구사항 확인 결과를 도면 버전과 함께 기록하고, 재확인이 필요한 항목을 표시합니다.
- ② 초품: 4M 변경 뒤 초품 검사 결과를 기록하고 걸러 봅니다.
- ③ 설비: 설비 상태와 교체 시점을 확인하고, 이상 건의 조치를 기록합니다.

모든 데이터는 가상입니다. 기록은 사용하는 브라우저에만 저장되고, 탭끼리 데이터를 주고받지 않습니다. 교체 한계, 수명 값, 점검 후보 규칙은 가정이며 현장에서 검증하지 않았습니다.
